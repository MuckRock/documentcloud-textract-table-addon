# DocumentCloud Textract OCR Table Add-On

This DocumentCloud Add-On uses [Amazon Textract](https://aws.amazon.com/textract/) to perform OCR on a document.

It uses the Analyze Text API to extract tables and places them in the text inline as markdown tables.
